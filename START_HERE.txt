이로운혜택 → Claude 인수인계 완성본 (2026-10-11)

이 폴더에는 실제 Replit 앱·서버 소스 272개 원본 내보내기 파일과 요구사항,
검증 이력, 미해결 오류, 설정 안내, 사용자가 제공한 원본 비교 영상이 있습니다.
이전 문서만 들어 있던 예비 ZIP을 대신하는 최종 인수인계 파일입니다.

지금 할 일
1. 이 ZIP을 다운로드해 압축을 풉니다.
2. Claude 데스크톱 앱에서 Code → Local → Select folder를 누릅니다.
3. 방금 풀린 Iroun-Project 폴더(package.json과 CLAUDE.md가 있는 폴더)를 선택합니다.
4. CLAUDE_START.txt의 내용을 복사해서 보냅니다.

웹 채팅만 사용하는 경우
우선 CLAUDE_START.txt와 HANDOFF 문서를 읽힐 수 있지만, 비공개 Replit 링크만으로
실제 파일 수정·실행 권한이 생기지는 않습니다. 실제 코드 작업에는 위의 로컬 폴더
연결 또는 사용자가 선택한 별도 코드 실행 환경이 필요합니다.

준비한 내용
- artifacts/iroun-benefits: Expo/React Native 모바일 앱
- artifacts/api-server: Express API와 테스트
- lib: DB 스키마와 공용 API 코드
- scripts: 기존 실행·검사 스크립트
- HANDOFF/README.ko.md: Replit에서 작성한 실행 방법과 남은 오류
- HANDOFF/PORTABILITY_REVIEW.ko.md: 외부 PC로 옮길 때 고칠 실행 환경 차이
- HANDOFF/CHATGPT: 상세 요구, 최신 변경, 검증 30항목, 설정표, 참고 영상
- HANDOFF/CHECKPOINT.json: 원본 소스 식별과 파일별 해시
- HANDOFF/INTEGRITY.json: 실제 다운로드·무결성 검사 결과
- SHA256SUMS.txt: 이 최종 묶음의 파일별 해시

중요
실제 비밀키·로그인 세션·운영 DB·고객 개인정보는 내보내지 않았습니다.
기존 Replit에는 그대로 남아 있습니다. 키 재발급은 필요하지 않으며 외부 개발 환경에서
실제 인증/API 검증할 때만 안전하게 설정해야 합니다.
최신 소스는 4개 메뉴로 바뀌어 있어 이전 5개 메뉴 요구와의 차이를 표시했습니다.
최신 코드를 무조건 되돌리지 않도록 Claude 시작 지시에 반영했습니다.

인수인계 준비가 완료된 것이며, Expo Go 실제 휴대폰 실행 오류까지 해결된 것은 아닙니다.
자동 Replit 수정/확인 작업은 인계 중 충돌을 막기 위해 중지했습니다.
이번에는 프로그램 설치나 새 PC에서의 실행 검사를 하지 않았습니다.
