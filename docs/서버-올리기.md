# 앱 서버 올리기 (Replit 없이)

앱 서버(`artifacts/api-server`)는 일반 Node 서버라서, Docker를 지원하는 서버 업체(Render, Railway, Fly 등)에 그대로 올라갑니다.
저장소 맨 위의 `Dockerfile`을 쓰면 됩니다.

## 준비물
1. 서버 업체 계정 (회사 명의)
2. PostgreSQL 데이터베이스 1개 (보통 같은 업체에서 함께 만듭니다)
3. 아래 환경변수 값

## 순서
1. 서버 업체에서 **Docker로 새 서비스 만들기** → 이 코드 저장소 연결 (Dockerfile 자동 인식)
2. PostgreSQL 만들기 → 연결 주소를 `DATABASE_URL`에 넣기
3. 아래 환경변수를 업체의 **Environment / Secrets** 화면에 넣기 (채팅·코드에 붙여넣지 않기)
4. 배포 → 처음 켜질 때 DB 구조(001~006)가 자동으로 만들어집니다
5. 공식 공고 기본 자료 4건은 새 DB일 때 서버가 자동으로 넣습니다(수동 실행: 아래 명령)
   `cd /app/artifacts/api-server && npx tsx src/seed-official.ts`
6. 서버 주소 확인: `https://iroun-api.onrender.com/api/healthz` (Render, 싱가포르, 2026-10-12 정상 확인)
7. 앱 빌드 설정에 `EXPO_PUBLIC_API_URL=https://<서버주소>` 넣고 앱을 다시 빌드

## 환경변수 (이름만, 값은 업체 화면에만)

| 이름 | 필수 | 내용 |
|---|---|---|
| DATABASE_URL | 필수 | PostgreSQL 연결 주소 |
| SESSION_SECRET | 필수 | 임의의 긴 난수 |
| CLERK_SECRET_KEY / CLERK_PUBLISHABLE_KEY | 필수 | Clerk 로그인(운영용 키) |
| PORT | 자동 | 업체가 넣어 줌. 없으면 8080 |
| CRM_APP_INBOUND_SECRET | 전산 연동 | 전산과 같은 64자리 hex. 넣으면 60초마다 계약 수신 시작 |
| CRM_BASE_URL | 선택 | 기본값: 회사 전산 주소 |
| BIZINFO_API_KEY, BIZINFO_API_APPROVED, BIZINFO_TERMS_APPROVED, IROUN_BIZINFO_APPROVED_SCOPE, IROUN_BIZINFO_DAILY_LIMIT | 공고 수집 | 기업마당 |
| DATA_GO_KR_SERVICE_KEY, IROUN_OFFICIAL_FEEDS_ENABLED, IROUN_FEED_INTERVAL_MINUTES | 공고 수집 | 공공데이터포털(정부24·복지) |
| EXPO_ACCESS_TOKEN, IROUN_PUSH_SEND_ENABLED | 알림 | 푸시 발송 |
| REVENUECAT_*, IROUN_BILLING_MODE, IROUN_*_MONTHLY_PRODUCT | 결제(나중에) | 출시 후 |
| IROUN_AUTO_MIGRATE=false | 선택 | DB 자동 구조 맞추기를 끌 때만 |
| IROUN_REVIEW_ACCOUNTS | 스토어 심사 | 심사용 Clerk 사용자 식별자(user_...)를 쉼표로. 서버 시작 시 1년 무상 이용권, 빼면 회수 |

기존 Replit 운영 DB의 고객 자료는 자동으로 옮기지 않습니다(별도 확인 후 진행).

- 새로 만든 DB에서 서버 시험 273건 통과
