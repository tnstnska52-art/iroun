# 계약 고객 창구: 모바일 웹·PC·설치 앱

회사에서 발급한 아이디와 비밀번호로 이용하는 고객 창구는 https://go.irowoon.com/package-conditions 입니다. 지원사업 신청, 서류 교체, 회사와의 대화는 이 창구의 CRM 자료를 사용합니다.

설치 앱의 홈·내혜택·내 정보에 **계약 고객 서비스 → 내 신청·대화 열기**를 추가했습니다. Clerk 가입 또는 휴대폰 로그인을 먼저 요구하지 않습니다. iOS에서는 Safari 화면, Android에서는 Custom Tab으로 같은 고객 창구를 열고, 앱의 웹 버전에서는 같은 탭으로 이동합니다. 화면을 닫으면 앱으로 돌아옵니다. 열기에 실패하면 다시 열기와 기본 브라우저로 열기를 제공합니다.

앱의 Clerk 계정과 CRM 계정은 서로 다른 인증 체계입니다. 자동으로 연결했다고 가정하거나 토큰·전화번호를 URL로 보내지 않습니다. iOS 앱 안의 Safari 화면은 일반 Safari와 로그인 쿠키가 다를 수 있으므로 처음에는 회사에서 받은 계정으로 로그인해야 합니다. 포털의 로그아웃과 로그인 유지 정책을 사용합니다.

기존 앱의 신청 기록·문의·서류 API와 이력을 변경하거나 CRM으로 이관하지 않습니다. 이 변경의 공통 고객관리 대상은 **계약 고객 서비스에서 진행한 신청과 대화**입니다. 기존 앱의 종 알림 및 푸시와 CRM 알림을 통합하는 변경도 아닙니다. CRM 답변은 고객 창구 안의 별도 답변 안내로 확인합니다.

## 검증과 배포

- 순수 이동 로직: `node --experimental-strip-types --test artifacts/iroun-benefits/lib/customer-portal.test.ts` (저장소 루트).
- 빠른 중복 클릭, iOS 닫기/취소, Android 열기, 웹 같은 탭 이동, 실패 후 재시도 및 명시적 브라우저 대체 경로를 검사합니다.
- `expo-web-browser`는 기존 의존성을 사용합니다. 새 SDK·권한·비밀키·DB 변경이 없습니다.
- 웹 고객 화면의 공개 버전과 앱 설치 파일의 배포는 별개입니다. GitHub에 코드가 반영되어도 설치된 앱은 자동으로 바뀌지 않습니다.
- 배포 전에 기존 EAS 프로젝트에서 새 설치 파일을 빌드하고 iPhone·Android 기기에서 로그인, 파일 선택/교체, 다운로드, 키보드, 닫기/복귀를 확인해야 합니다. 테스트는 가짜 고객 계정으로 진행합니다.
- 이번 작업 환경에는 Expo 빌드 인증 및 Android/iOS 실기기 환경이 없어 설치 파일 생성·스토어 제출·실기기 성공을 확인하지 않았습니다.

참고: https://docs.expo.dev/versions/v57.0.0/sdk/webbrowser/
