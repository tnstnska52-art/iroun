## 현재 넘겨야 할 주요 미해결/미검증

1. **Expo Go 기본 실행 실패**: 실제 오류 로그와 동일 실행 경로 재현 필요. 푸시 자격증명·스토어 서명 준비와 별개로 먼저 진단한다.
2. **iPhone형 미리보기 manifest JSON 파싱**: 과거 특정 플랫폼정보 없는 Expo 요청에 HTML이 반환된 재현은 있었으나 실제 사용자 실패 요청과 같은지 확인되지 않았다. 원인 확정이나 수정완료라고 표현하지 않는다.
3. **반복 502/개발 서버 종료**: 새벽에 복구 후 재발. 일부 실행관리/제한재시도/로그 보완, 단기 생존검사 존재. 공동중단 원인과 장기 생존은 미확정. 관측 OOM0·테스트의 종료명령 없음은 원인 부재의 최종 증명이 아니다.
4. **실기기/푸시**: 서명 설치, FCM/APNs/EAS 실제 연결, 잠금화면 수신과 알림 탭 이동, VoiceOver/TalkBack, 네이티브 키보드 미검증.
5. **공식 수집**: 실제 계정 한도/이용조건/범위, 검토대기 원문 대조, 승인된 자동수집·중복/제외/실패 검증의 최신 완료 여부 미확인.
6. **회사 외부 설정**: 대표 계정의 소유확인 기반 관리자 지정, 실제 직원 연락처/회사 문의/정책 확정. 회사 정책 전체 편집 UI 존재는 확인되지 않음.
